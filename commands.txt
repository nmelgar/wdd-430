Angular CLI (Command Line Interface)

    Common commands:
        Creating new projects: ng new
        Serving the app: ng serve
        Generating files: ng generate component/service/pipe/etc.
        Building for production: ng build

// create new project
// routing not needed for simple apps
ng new my-first-angular-app --no-strict --standalone false --routing false

// navigate into project directory
cd my-first-angular-app

// create new component
ng generate component component-name --flat (in current folder)
ng generate component component-name (in new folder)

// serve the application
ng serve -o
